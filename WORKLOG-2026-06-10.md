## 2. Bug fix — dev server truncating the API
- **Symptom:** the Werkzeug dev server intermittently dropped the body of the
  ~7.8 MB `/api/manuscripts` response on Windows/Python 3.14, so the browser got
  truncated JSON and **no manuscripts loaded** (sidebar showed 0/1).
- **Fix (`app.py`):** added a gzip `after_request` handler (≈7.8 MB → ~1 MB, well
  within what the dev server delivers reliably) and `threaded=True`.
- **Follow-up (`script.js`):** added `fetchJson()` retry-with-backoff so a
  transient first-request failure self-heals instead of falling back to the
  1-manuscript inline default.

## 3. Manuscript Networks — feature work (`static/manuscript_network.js`, `style.css`)
- **Routes now match the Route Planner exactly** — reuse the planner's
  `SEL_ROAD_STYLE` / `SEL_SEA_STYLE` / `SEL_RIVER_STYLE` instead of a divergent
  local palette. They can no longer drift apart.
- **Both routes drawn** — the **Fastest** (horse+river+sea) and the **Land**
  (foot/river) route, overlaid, each in the planner's styling.
- **Editable endpoints** — Composition and Recipient are now **searchable city

- **Route-view toggle** — a segmented **Land / Fastest / Both** control.

- **Find-site orbs in the network** — reuses the Manuscripts browser's

## 4. Reader — recto/verso breaks in the English (`app.py`, reader)
- Taught `parse_manuscript()` to read `FOLIO` headers inside `[TRANSLATION]`, not

## 5. Faithful-translation pass (37 NT papyri)
Replaced ESV-style verse text with **literal translations of each papyrus's actual
Greek** — real word order, historic-present tense, variant readings, and text that
**stops where the fragment stops** (e.g. P52 ends mid-sentence at 18:38). Each
carries recto/verso breaks.

Done: **P52, P80, P76, P78, P140, P121, P93, P95, P12, P107, P128, P112, P113,
P122, P60, P2, P7, P102, P29, P36, P62, P9, P63, P71, P73, P10, P141, P31, P23,
P55, P111, P119, P82, P94, P35, P103, P42.**

Notable variants flagged (Greek left untouched): P9 (1 John 4:16 *Christ* for
*God*), P63 (John 3:16 plus "into the world"), P112 (Acts 26:32 longer ending),
P10 (Romans school-exercise omits 1:6). *~97 NT manuscripts remain for this pass.*

## 6. Firecrawl web-scraping pipeline
- Got Firecrawl working. **Gotcha:** this machine does TLS inspection, so Python's
  certifi bundle rejects the cert (`CERTIFICATE_VERIFY_FAILED`). Fix:
  `truststore.inject_into_ssl()` (trusts the Windows cert store; verification stays
  on). Firecrawl also **clears papyri.info's "Anubis" bot-gate** that blocks plain
  WebFetch.
- New: **`firecrawl_scrape.py`** (generic scrape-any-URL helper; key from
  `FIRECRAWL_API_KEY` env var, never hardcoded).
- New skill: **`.claude/skills/scrape-manuscript/`** (`SKILL.md` +
  `scripts/scrape_papyrus.py`) — pulls documentary papyri from papyri.info/DDbDP,
  extracts TM / origin / date / **shelf** (`Inv. no.`) / subjects + Greek, and
  documents the `.txt` build for receipts/contracts/letters. Companion to
  `grab-manuscript` (which is NTVMR-only and has no documentary papyri).

## 7. Sidebar + map features
- **Shelf numbers in the sidebar** — documentary genres now show each papyrus's
